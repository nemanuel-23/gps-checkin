# GPS Predator Bounty Check-In

Volunteer check-in app for the Grand Passage Sportsmen Youth Predator Bounty Program.

- Open: https://nemanuel-23.github.io/gps-checkin/
- Data lives in the program's Google Sheet, reached through the Apps Script link in `config.js`. No participant data is stored in this repository.
- Volunteers need the check-in password; admin tools need the admin password.
- QR scanning uses [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0, see `jsqr-LICENSE.txt`).
